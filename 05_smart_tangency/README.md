# 05 · Smart Tangency（强化学习选调仓时点和风险档位）

**论文**：*Smart Tangency Portfolio: Deep Reinforcement Learning for Dynamic Rebalancing and Risk–Return Trade-Off*，Int. J. Financial Stud. 2025, 13, 227

## 论文在做什么
智能体不直接给权重，只选两个数：
- **λ**（1—100）：在有效前沿上取哪个位置（目标收益 = 最低资产均值 + λ% × 极差）；
- **h**（5—60 天）：多少个交易日之后再重新优化。

权重交给传统优化器，风险度量有三种：方差、半方差、CVaR（95%）。算法 PPO、A2C，共 6 个智能体。滚动：训练 2 年 → 验证 2 年 → 测试 2 年。“集成”= 验证期夏普最高的那个智能体拿去跑测试期。奖励是持有期的对数收益。

## 文件
| 文件 | 作用 |
|---|---|
| `fetch_us.py` | 下载美股行业 ETF、道指成分股、SPY 的复权日线（Yahoo Finance） |
| `frontier.py` | 预先算好每个交易日、三种风险度量、20 档 λ 的前沿权重（回看 252 天） |
| `smart_tangency.py` | 环境 + PPO / A2C 训练 + 滚动测试 |
| `summary.py` | 汇总：6 个智能体、集成、三种切点组合基准（30 天重算）、等权、SPY，以及**随机选 λ 和 h 的对照** |

```bash
python3 fetch_us.py
python3 frontier.py etf
STEPS=30000 python3 smart_tangency.py etf ppo &   # 两个算法可以并行
STEPS=30000 python3 smart_tangency.py etf a2c
python3 summary.py etf
```

单个随机种子在 2007—2022 的年化分布：平均 10.6%，最低 7.9%，最高 13.7%；夏普平均 0.62，最高 0.82。

## 要如实说明的地方
- 表面上复现出来了：集成年化 11.7%（论文 11.3%），6 个智能体的回撤都明显小于切点组合基准和 SPY。
- **但加一个“随机选 λ 和 h”的对照之后，结论变了**：随机策略的夏普（平均 0.62）和智能体（0.54—0.76）、集成（0.63）在同一水平，智能体的年化都落在随机种子的分布范围（7.9%—13.7%）附近。智能体学到的平均动作（λ≈60、h≈32 天）也接近均匀随机的均值。也就是说，相对切点组合基准的改善，主要来自“在前沿上换着位置拿、而不是永远押在最大夏普那一点”，看不出是强化学习学到了择时。论文没有报告这个对照。
- 2023 年之后，集成和多数智能体都没有跑赢 SPY 和等权。
- 与论文的差别：9 只行业 ETF（论文 12 只，名单未列全）；λ 和 h 各按 5 一档（论文 λ 是 1—100 的整数）；状态特征 11 个（论文 34 个）；每个智能体训练 3 万步、1 个随机种子；集成按验证期夏普选（论文按夏普的中位数）；没有计交易成本；道指成分股那一组没跑（脚本支持 `djia`）。
