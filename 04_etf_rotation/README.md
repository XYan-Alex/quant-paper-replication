# 04 · ETF 行业轮动

**论文**：《基于动量与风险优化双重视角的ETF行业轮动策略研究》，汉斯出版社《金融》，2026

## 论文在做什么
13 只 ETF，每月第一个交易日开盘调仓：
1. 动量得分 = 25 日回归斜率（年化）× R²；
2. 相关矩阵向单位阵收缩 0.5；
3. 均值方差优化（γ = 2），权重变化不到 1% 不调。

```bash
python3 fetch_etf.py     # 新浪不复权日线 + 拆分日修正（未计分红）
python3 etf_rot.py
```
