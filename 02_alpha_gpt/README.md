# 02 · Alpha-GPT

**论文**：Wang et al., *Alpha-GPT: Human-AI Interactive Alpha Mining for Quantitative Investment*，[arXiv:2308.00016](https://arxiv.org/abs/2308.00016)

## 论文在做什么
让大模型站在人和算法中间挖因子：人用大白话说交易想法 → 大模型翻成公式（种子）→ 遗传搜索做变异、交叉，按 IC 留强去弱（搜索增强）→ 人看结果、给反馈，再来一轮。

## 文件
| 文件 | 作用 |
|---|---|
| `eng.py` | 公式引擎（24 种运算：时间序列 / 截面 / 逐元素）+ 遗传搜索；收益先对成交额规模做中性化 |
| `ideas.py` | 16 个交易想法和对应的种子公式 |
| `it_seeds.json` | “交互”这一步：看完第一轮搜索结果后，给每个想法重写的 3 个修正公式（由大模型 Claude 完成） |
| `run_ag.py` | 对每个想法做遗传搜索；`run_rand.py` 是从随机公式出发的纯算法对照 |
| `pool_bt.py` | 因子池去冗余（相关 > 0.7 剔除）、等权合成、月频前 10% 回测（买卖各 4‰） |
| `runs/` | 每次搜索的完整记录（每一代的最优公式、样本内外 IC） |

## 运行
```bash
export AG_H=20 AG_STEP=5                                        # 预测 20 日收益
python3 run_ag.py h20se_a 0,2,4,6,8,10,12,14 10                 # 搜索增强（偶数号想法）
python3 run_ag.py h20se_b 1,3,5,7,9,11,13,15 10
python3 run_ag.py h20it_a 0,2,4,6,8,10,12,14 10 it_seeds.json   # 交互后再搜索
python3 run_ag.py h20it_b 1,3,5,7,9,11,13,15 10 it_seeds.json
python3 pool_bt.py h20se,h20it                                  # 人机交互 + 搜索 的因子池
python3 pool_bt.py seed                                         # 只用 16 个种子
python3 pool_bt.py rnd                                          # 纯算法
```
不设 `AG_H` 时预测 5 日收益（对应 `runs/ag_se_*`、`ag_it_*`）。

## 结果
样本内 2016—2021，样本外 2022-01 至 2026-11（搜索全程没用过样本外数据）。股票池：沪深300 + 中证500 + 中证1000 历史成分。

**平均 |Rank IC|（对应论文表 4）**

| 阶段 | 论文 | 我们（样本内 / 样本外） |
|---|---|---|
| 种子公式 | 0.58% | 3.07% / 2.72% |
| 搜索增强 | 1.23% | 7.49% / 7.10% |
| 交互 + 搜索 | 2.23% | 7.95% / 7.57% |

**模拟组合，样本外每年跑赢指数（%）**

| 因子池 | 中证1000 | 中证500 | 沪深300 |
|---|---|---|---|
| 只用人写的 16 个种子 | 10.9 | 7.6 | −0.3 |
| 纯算法（随机起点） | 9.3 | 8.4 | 9.2 |
| 人机交互 + 搜索 | 9.5 | 8.0 | 10.4 |

## 要如实说明的地方
- “搜索增强把 IC 提高两到三倍”复现出来了，样本外同样成立。
- 组合层面，人机交互相对纯算法的优势很小；中证1000 上也没有超过“只用人写的种子”。
- **中证1000 的 9.5 个点大部分来自 2026 年 7 月这一个月**（指数当月跌 19.7%，组合涨 12%）；去掉这个月，每年只跑赢约 2.2 个点。
- 预测目标从 5 日改成 20 日，是看过 5 日结果之后改的。
- 搜索出来的公式经常偏离原想法，多数最后落在低波动、量价相关这几类已知规律上。
- 论文里的高频比赛成绩和大赛排名无法复现；“想法—公式一致性打分”没做。
- `pool_bt.py rnd` 重新生成的纯算法池，与当时存档的分数相关系数为 0.995（筛选细节略有出入）；另外三个池完全一致。
- 过拟合检验见 [`09_overfitting_check`](../09_overfitting_check)。
