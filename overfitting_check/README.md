# 09 · 过拟合检验（PBO、DSR）

对 01、02 两篇的复现结果补做两项“回测是不是挑出来的”检验。

- **PBO**（回测过拟合概率，Bailey et al. 的 CSCV 方法）：把月度超额收益切成 S 块，所有“一半样本内、一半样本外”的组合都轮一遍，看样本内夏普最高的方案在样本外掉到中位数以下的比例。越接近 0 越好，0.5 以上不过关。
- **DSR**（紧缩夏普，Bailey & López de Prado 2014）：按试过的方案数和各方案夏普的离散程度，算出“全都无效时最好那个也能有多高”的门槛，再算被选方案超过门槛的概率。通常要大于 0.95。

| 文件 | 作用 |
|---|---|
| `stats.py` | PBO、DSR 的实现 |
| `dmfm_of.py` / `ag_of.py` | 重跑每个试过的方案，导出月度超额收益（存到 `results/overfitting_check/`） |
| `analyze.py` | 出结果 |

## 结果
| | 中证1000 | 中证500 | 沪深300 |
|---|---|---|---|
| 01 DMFM · PBO（12—14 个方案） | 0.12 | **0.59** | 0.26 |
| 01 DMFM · DSR | 0.61 | 0.23 | 0.35 |
| 02 Alpha-GPT · PBO（8 个方案） | 0.30 | 0.19 | 0.16 |
| 02 Alpha-GPT · DSR | 0.64 | 0.57 | 0.60 |

**DSR 两篇都没过线。** 主要原因不是试得太多，而是样本只有 5—6 年、超额的年化信息比率只有 0.3—0.7，即使只试过一个方案也不显著。PBO 除了 DMFM 的中证500 以外都过关。
