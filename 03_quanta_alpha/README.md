# 03 · QuantaAlpha（精简版）

**论文**：*QuantaAlpha: An Evolutionary Framework for LLM-Driven Alpha Mining*，[arXiv:2602.07085](https://arxiv.org/abs/2602.07085)

## 论文在做什么
把“假设 → 公式 → 回测”当成一条轨迹来进化：多样化初始化 → 对表现差的环节做定点变异 → 把好轨迹交叉重组；同时用公式长度上限和“与已有因子的公共子树占比”两道闸门控制复杂度和冗余。因子池交给 LightGBM 预测收益。

## 我们做的（精简版）
- 三轮：初始化 16 个 → 变异 +40 个（闸门拒掉 8 个）→ 交叉 +24 个。公式由大模型 Claude 写，直接写在 `qa.py` 里（`R0 / R1 / R2`）。
- 因子池 → LightGBM（训练 2016—2020，验证 2021，测试 2022-01 至 2025-12），预测次日收益；持仓规则 TopkDropout(50, 5)，买 0.05%、卖 0.15%。
- 依赖 `02_alpha_gpt/eng.py` 的公式引擎。

```bash
python3 qa.py
```

## 结果（测试集 2022-01 至 2025-12）
| 因子池 | 沪深300 IC | 沪深300 年化超额 | 迁移到中证500 累计超额 |
|---|---|---|---|
| 初始化 16 个 | 0.0088 | 4.45% | −10.5% |
| + 变异 56 个 | 0.0131 | 6.83% | +9.4% |
| + 交叉 80 个 | 0.0112 | 4.53% | +17.3% |
| 论文（约 150 个因子） | 0.0472 | 4.68% | +40.28% |

## 要如实说明的地方
- 变异这一步的提升复现出来了（和论文的消融结论一致）；交叉在沪深300 上没有继续提升。
- IC 绝对值远低于论文（0.011—0.013 对 0.047）：因子数量只有论文的一半，也没有论文那样多轮自动进化。
- 这是精简版，不是论文开源代码的完整运行。
