# 07 · Neural Shrinkage（神经网络收缩协方差）

**论文**：*Neural Shrinkage of Indefinite Pairwise Correlations*，[arXiv:2608.30446](https://arxiv.org/abs/2608.30446)

## 论文在做什么
股票上市时间不同、时有停牌。两两按“共同有数据的那段”算相关系数，信息用得最充分，但拼出来的相关矩阵可能不是正定的，没法直接做最小方差组合。论文的办法：
1. 对收益做一个可学习的滞后变换（越近的权重越大，并做软截断）；
2. 算两两相关矩阵，做特征分解，得到**带符号**的特征值；
3. 给每个特征方向算一个“有效样本长度” $\tau_k=\sum_{ij}Q_{ik}^2T_{ij}Q_{jk}^2$；
4. 把 $(\lambda_k,\sqrt n,\sqrt{\tau_k},n/\tau_k)$ 按顺序喂给双向 GRU，输出一组正的逆特征值，重建出正定的相关矩阵；
5. 端到端训练，损失 = 未来 5 天最小方差组合的实际方差。

## 我们做的（A 股版）
- 数据：`01_dmfm/prices.py` 生成的日线，停牌日记为缺失。
- 训练：2010—2015 年随机抽样（每次 50—250 只股票、回看 250—750 天），3000 步，只训练一次。
- 样本外：2016-01 至 2026-11，每 5 个交易日调仓一次，共 527 期。每期从中证1000 成分股里随机取 500 只、回看 500 天（至少 60 个有效日即纳入）。所有估计量都送进同一个只做多的最小方差优化器。两两相关矩阵平均有 13% 的特征值为负。

```bash
python3 neural_shrinkage.py train
python3 neural_shrinkage.py eval
```

## 结果（样本外 2016-01 至 2026-11）
| 协方差估计 | 5 日波动（年化） | 日波动（年化） | 年化收益 | 夏普 | 最大回撤 |
|---|---|---|---|---|---|
| **神经网络收缩（论文方法）** | **19.18%** | **17.04%** | 2.31% | 0.22 | −46.5% |
| 两两相关 + 线性收缩 | 19.69% | 18.17% | −2.70% | −0.06 | −45.5% |
| 两两相关 + 最近相关矩阵（Higham） | 20.12% | 18.23% | −4.99% | −0.19 | −55.4% |
| 只用波动率（对角） | 24.06% | 22.89% | 5.32% | 0.34 | −47.2% |
| 等权 | 25.97% | 24.75% | 4.01% | 0.28 | −49.5% |

论文报告：相对次优估计量，5 日波动降低约 20%，夏普提高约 40%。

## 要如实说明的地方
- **方向复现出来了，幅度小得多**：神经网络估计的组合波动最低，但相对次优只低 2.6%（5 日口径）到 6.2%（日口径），不是论文的 20%。
- 不计交易成本；每期随机换一批股票，换手率偏高，不代表可交易的结果。
- 与论文的差别：A 股而不是美股；只训练一次而不是逐年扩展训练；训练步数和样本规模都小得多；没有券商级撮合仿真；对照的线性收缩用的是启发式强度，不是论文里的全部对照方法；波动率分支加了一条乘法直连。
- 最小方差组合本身在这个区间收益不高（夏普 0.2 左右），这里比的是“谁估的风险更准”，不是谁更赚钱。
