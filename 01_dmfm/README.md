# 01 · 深度多因子模型（DMFM）

**论文**：Wei, Dai, Lin, *Factor Investing with a Deep Multi-Factor Model*，[arXiv:2210.12462](https://arxiv.org/abs/2210.12462)

## 论文在做什么
每个月给指数成分股打分，选分数最高的 10% 等权持有。模型分五步：
1. 用多层感知机把 63 个风格因子编码成“股票画像”；
2. 用图注意力（GAT）算出同行业股票的影响，减掉（行业中性）；
3. 再算全市场的影响，减掉（市场中性）；
4. 训练目标不是猜涨幅，而是让分数的 IC、ICIR、因子收益尽量高；
5. 因子注意力：用原始 63 个因子的非负加权组合去逼近模型分数，权重就是“模型在看什么”。

## 文件
| 文件 | 作用 |
|---|---|
| `prices.py` | 读日线二进制 → `prices.npz`（日期 × 股票宽表，含三大指数成分与指数点位） |
| `fetch_fund.py` | 抓季度业绩报表、资产负债表 |
| `factors.py` | 造 63 个因子（反转 12、动量 10、规模 5、价值 16、质量 20），按股票池切成训练张量 `panel_*.npz` |
| `model.py` | 按论文结构的 DMFM，以及 MLP、MLP+GAT 两个对照；半年滚动训练 |
| `lite.py` | 轻量版：用行业 / 全市场等权平均代替图注意力，加一条线性直连，多训几轮、三个种子平均 |
| `backtest.py` | 月度调仓回测（信号次日收盘换仓、买卖各 4‰），含等权、滚动线性回归两个不用训练的基线 |
| `blend.py` | 几种分数的组合对比，并保存“等权 + lite”这一版分数 |

## 运行
```bash
python3 prices.py && python3 fetch_fund.py && python3 factors.py
python3 model.py csi1000 dmfm,mlp,mgat      # 很慢（CPU 上几小时）
python3 lite.py csi1000
python3 blend.py csi1000
python3 backtest.py csi1000
```

## 结果（每年跑赢指数，%）
论文区间 2016-01 至 2022-06；“之后”= 2022-07 至 2026-11。

| 做法 | 中证1000 | 中证500 | 沪深300 | 中证1000 之后 |
|---|---|---|---|---|
| 论文报告（DMFM） | 16.36 | 9.03 | 7.85 | — |
| 63 个因子等权 | 11.42 | 5.98 | 7.96 | 3.79 |
| 滚动线性回归 | 14.78 | 1.98 | 0.98 | 6.39 |
| MLP | 7.44 | 1.95 | 1.42 | 3.76 |
| MLP + GAT | 4.82 | 1.41 | −0.87 | 2.61 |
| 按论文结构（DMFM） | 7.39 | 6.33 | 1.02 | 4.11 |
| 轻量版 lite | 11.74 | — | 4.51 | 4.84 |
| **等权 + lite** | **14.40** | **6.44** | **7.72** | **6.92** |

## 要如实说明的地方
- **按论文结构直接复现没有达到论文水平**（中证1000：7.39 对 16.36），也没有跑赢“63 个因子直接等权”。
- “等权 + lite”这个组合是看过论文区间的结果之后选出来的，有事后挑选的成分；2022-07 之后的区间没有参与挑选。
- 过拟合检验见 [`overfitting_check`](../overfitting_check)：DSR 三个股票池都没过线，中证500 的 PBO 为 0.59。
- 与论文口径的差别：63 个因子是按五类自己造的（论文没给清单）；财报按法定披露截止日对齐，不是真实公告日；行业用现行申万一级；算力有限（2 核 CPU），按论文结构的模型只跑了 1 个种子，中证500 / 1000 训练时隔 4 / 5 天取一天。
